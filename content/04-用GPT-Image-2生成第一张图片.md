# 用 GPT Image 2，在无限画布里生成第一张图片

归属：图片生成。预览入口：`#track/image`。本课面向普通新手，推荐电脑浏览器；不用写代码或安装画布。模型 ID：`gpt-image-2`。网页：<https://canvas.modelaryx.com/>，界面核对版本 v0.4.0，日期 2026-10-24。

学完能做什么：在画布上看到一张符合中文描述的图片，下载后能在电脑打开，并找到本站使用记录。本次练习是“雨天，窗边的一只橘猫”。

## 1. 准备生图密钥

1. 登录只因 API，在模型广场搜索 `gpt-image-2`，查看包含它的生图分组、当前价格单位和使用条件。
2. 确认有对应余额或订阅权益。打开 API 密钥，准备一把属于支持该模型的 GPT 生图分组的普通 API Key。新建时选 OpenAI 及自己有权限的生图组，名称可写“图片入门练习”。
3. 只在自己的画布配置中填写密钥；不要发到聊天或截图中。

GPT 文字分组不等于 GPT 生图分组；视频站画布专用 Key 不适用于本课。外部 Canvas 和本站视频站是不同入口。

入口：[模型广场](https://www.yydsapi.uno/model-plaza)、[API 密钥](https://www.yydsapi.uno/keys)。位置图复用 `preview/assets/site-introduction/keys.jpg`，明确它仅用于找入口，不能照抄其他厂商与用途。

## 2. 配置本站渠道

打开 Canvas，点右上角“配置”（画布编辑页是滑杆图标）。在“渠道”标签中，把未使用的默认渠道改为“只因 API”；已有其他服务时，点“新增渠道”单独添加。

| 字段 | 填写内容 |
| --- | --- |
| 渠道名称 | 只因 API |
| Base URL | `https://image.yydsapi.uno` |
| API Key | 自己的本站生图密钥，保持隐藏 |
| 模型列表 | 包含 `gpt-image-2` |

可点渠道的“拉取模型”，也可在模型列表输入完整 ID 并按 Enter 添加。手动添加模型名不代表获得权限，也不能修复地址或认证错误。

切到“模型”标签，检查“生图模型可选项”包含 `gpt-image-2（只因 API）`，把“默认生图模型”选为同一项，点“完成”。本课只用生图相关两行。括号中的渠道名也要一致。

生图统一使用专用域名 `https://image.yydsapi.uno`。此画布会自动补 `/v1`；Base URL 不填完整的生图接口。该域名用于 API 配置，登录、创建密钥和查询用量仍在 `https://www.yydsapi.uno`。配置与画布主要在浏览器本地保存，不要在公共电脑保留密钥，不分享含密钥的配置或截图。

配图：[渠道配置](../preview/assets/image-canvas/channel-config-image-domain.jpg)、[模型设置](../preview/assets/image-canvas/model-settings.jpg)。教学截图的 API Key 留空；预置其他模型不表示密钥都能使用。

完成标志：生图模型为 `gpt-image-2（只因 API）`。这只说明配置已选好，实际调用要由后面的出图确认。

## 3. 新建画布和图片节点

1. 打开“我的画布”，点“新建画布”，会进入新画布编辑页。
2. 可双击左上角名称改成“我的第一张图片”。
3. 点底部工具栏的小山形“图片”图标。出现“空图片节点”，选中后下方是输入框、模型、参数和生成按钮。
4. 如果看不到输入框，用左下角缩放滑杆缩小查看。

配图：[空画布入口](../preview/assets/image-canvas/empty-canvas.jpg)。节点是摆放在画布里的内容卡片。

## 4. 输入第一条提示词

提示词就是画面要求。先说明主体、场景、风格和构图：

```text
一只橘猫坐在窗边的木桌上，旁边放着一杯咖啡。窗外下着小雨，室内温暖柔和。清新插画风格，主体居中，画面简洁，不要文字，不要水印。
```

粘贴到“描述要生成的图片内容”输入框。核对模型 `gpt-image-2`，渠道为“只因 API”。先不追求多人、大量细节和复杂文字。提示词是要求，不是质量保证，生成后仍要检查。

配图：[图片节点，生成前](../preview/assets/image-canvas/image-node.jpg)。空框是真实的生成前状态，不是模型结果。

## 5. 先设一张，再点生成

画布默认是 **3 张**，请先主动改成 **1 张**，控制首次练习的任务数量。

点节点下方参数摘要，打开“图像设置”：

| 参数 | 首次练习 |
| --- | --- |
| 质量 | 自动 |
| W × H | 1024 × 1024 |
| 宽高比 | 1:1 |
| 生成张数 | 1 张 |

在面板内向下滚动找到“生成张数”。收起面板，确认摘要为“自动 · 1:1 · 1 张”。所选分组如果有不同要求，以当前说明为准。

可选：在“配置 → 生成偏好”把“画布默认生图张数”设为 1。它影响新节点；已有节点仍需检查。

配图：[质量与尺寸](../preview/assets/image-canvas/image-settings.jpg)、[单张数量](../preview/assets/image-canvas/image-count.jpg)。按钮中的闪电或“0”不是本站的免费承诺，也不是账单。

## 6. 生成并检查

1. 核对本站渠道、`gpt-image-2`、1 张，再点提示词右侧的向上箭头“生成”。这一步发起实际模型请求，可能产生费用。
2. 等待，不要连续点。成功后画布的图片节点会显示真实图像；空白、进度、错误都不是完成。
3. 检查橘猫、木桌、咖啡、雨天窗景是否出现，主体是否清楚，有没有多余肢体、奇怪物体或不想要的文字。

画面不需要与别人的一模一样。超时或失败先查节点与本站记录，确认后再决定是否重试。

## 7. 下载成品与备份画布

1. 选中生成后的图片节点，在上方工具条点向下箭头“下载”（提示为“下载图片”）；如果收进更多菜单，展开查找。空节点没有可下载的成品。
2. 从浏览器下载记录或电脑“下载”文件夹找到图片，双击打开，确认完整可查看。重命名时保留文件扩展名。
3. 通过左上角画布菜单返回“我的画布”，在当前卡片右下角点向下箭头“导出”，保存 `.zip` 画布备份。以后使用“导入画布”恢复。

| 保存方式 | 用途 |
| --- | --- |
| 图片文件 | 查看、使用和分享作品 |
| 画布 ZIP | 保存项目结构与可用素材，继续编辑 |
| 浏览器中的画布 | 原处继续；换设备或清理站点数据可能丢失 |

配图：[画布库及导出入口](../preview/assets/image-canvas/canvas-library.jpg)。图片下载与项目备份是两个动作。

## 8. 可选练习与消费核对

保存第一张后，再新建一个空图片节点，只把橘猫换成白猫，其他描述和参数不变。这是新的生成，可能再次收费：

```text
一只白猫坐在窗边的木桌上，旁边放着一杯咖啡。窗外下着小雨，室内温暖柔和。清新插画风格，主体居中，画面简洁，不要文字，不要水印。
```

比较两张图。重新生成可能改变其他细节，不保证固定构图；要保留原图进行精确修改，后续学习参考图和图片编辑。

打开[本站使用记录](https://www.yydsapi.uno/usage)，按时间、密钥和 `gpt-image-2` 筛选，核对模型、分组、状态与费用。画布本地保存和本站调用记录各有用途。数量、自动重试或多次点击可能产生多次请求，不以节点数量直接判断账单。找不到时检查筛选并稍后刷新，不为找记录反复生成。

## 9. 常见问题

| 现象 | 先检查 |
| --- | --- |
| 列表没有模型 | 渠道的地址/Key，拉取或手动添加；生图可选项和节点渠道。模型列表不授予调用权限 |
| 401 / 403 | Key 是否有效、Base URL 是否为 `https://image.yydsapi.uno`、是否支持模型的普通 GPT 生图分组 Key |
| 额度不足 / 429 | 对应分组权益、密钥限额、并发；停止重复提交，等待并检查 |
| 网络错误 / 超时 | 地址、网络、节点和本站记录；网页超时不等于上游没处理 |
| 400 / response_format | 先回单张1024方图与自动质量，查分组能力；明确字段不兼容时附版本和原始错误给维护者 |
| 换浏览器找不到 | 回原浏览器查数据，从下载文件或画布 ZIP 备份恢复 |
| 结果不合意 | 简化主体和场景，每次只改一个条件；重新生成不能逐像素保留上一张 |

求助只提供时间、模型、渠道、Canvas 版本和已脱敏错误，不包含完整密钥。
