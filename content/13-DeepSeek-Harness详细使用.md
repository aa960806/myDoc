# 把 DeepSeek Harness 用顺手

更新：2026.11.04。面向第一次使用 Agent 的普通用户。网页入口：`#tool/deepseek-harness`。

准备普通 Claude 分组 API Key、一个空的 `agent-practice` 文件夹，并安装 Harness 桌面端或启动官方本机 Web UI。学习顺序：安装 → 配置模型 → 选工作区 → 先计划再执行 → 检查文件。会话协作、扩展和自动化在第一次成功后继续学习。

完成后，你应当能选中本站模型，创建并修改 `learning-plan.md`，在电脑中找到文件，并核对本站使用记录。

## 01 先认识工具与学习路线

锚点：`agent-fit`

DeepSeek Harness 是 DeepSeek 开源的 Agent 工具，有桌面端，也可以在自己的电脑上启动网页界面。它把模型、文件夹和工具放在一起，可以读取材料、提出计划、修改文件，再由你检查成果。

工具名包含 DeepSeek，也能接入其他厂商模型。本课使用**本站 Claude 分组 API Key + Anthropic Messages** 路线。

| 概念 | 作用 |
| --- | --- |
| 模型服务 | 负责理解与生成；配置供应商、协议、Key 和模型。 |
| 工作区 | 电脑上的文件目录，是练习文件的存放位置。 |
| 会话 | 保留一件事情的要求、执行过程和后续修改。 |

网页提供四步流程示意：选模型 → 选练习目录 → 创建并修改文件 → 打开成果和核对消费。它是教学示意，不是客户端截图。

## 02 安装桌面端或启动 Web UI

锚点：`agent-download`

1. 打开 [DeepSeek Harness 官网](https://www.deepseek.com/harness/)，展开下载选项。当前提供 Windows 64 位（Windows 10+）和 macOS Apple 芯片（macOS 13+）入口，以官网下载页当前支持范围为准。
2. 运行安装包，按向导完成，打开应用。
3. 找到**设置 → 模型**。下一节添加本站服务，暂时不用安装额外插件。

网页保留官网下载入口配图，采集日期为 2026.10.24。Harness 当前为预览版，按钮和可用功能可能随版本、插件和配置调整。

### 可选：在电脑上启动官方 Web UI

先安装 Node.js，在电脑“文档”中新建 `agent-practice`，从这个目录打开 PowerShell，再运行：

```powershell
npx.cmd @deepseek-ai/dsh web
```

首次运行按 npm 提示获取官方包。打开终端实际打印的地址，默认是 `http://127.0.0.1:3080`。使用期间保持终端进程运行。启动目录是默认文件位置，进入网页后仍要明确选择本次练习的工作区。

完成检查：应用或本机网页能打开，能进入设置的模型页面。

## 03 配置本站模型服务

锚点：`agent-connect`

### 第一步：准备 Key 和可用模型

到本站 [API 密钥](https://www.yydsapi.uno/keys)准备一把有效、额度可用的普通 Claude 分组 Key，确认它允许调用 `claude-sonnet-4-6`。若分组提供其他模型，使用对应的精确模型 ID。

Key 填在自己的 Harness 设置里。视频站专用 Key 用于视频站登录，不能代替普通模型 Key。

### 第二步：添加自定义提供商

打开**设置 → 模型 → 添加模型提供商**，将默认的“第三方模型提供商”切换为**自定义模型 API**。

| 字段 | 本课填写值 |
| --- | --- |
| Provider ID | `rainapi`，使用小写，保存后作为固定标识 |
| 显示名称 | 只因 API · Claude |
| API 地址 / 基础 URL | `https://www.yydsapi.uno` |
| API 协议 | Anthropic Messages |
| API 密钥 | 自己的完整普通 Claude 分组 API Key |
| 模型 ID | `claude-sonnet-4-6`，以这把 Key 实际可用模型为准 |

地址填到域名，不追加 `/v1/messages`。Provider ID 是固定标识，显示名称可以后续调整。

网页提供折叠的官方中文模型表单图用于辨认字段。官方图默认展示的 OpenAI 协议与示例地址，必须按本课表格换为 Anthropic Messages 和本站根地址。

图片来源：[官方中文表单原图](https://raw.githubusercontent.com/deepseek-ai/deepseek-harness/master/docs/user/guide/providers-custom-form.zh.png)。

### 第三步：添加模型，保存并选中

在模型目录中手动添加精确模型 ID，至少保留一个模型后保存。也可以尝试**获取可用模型 → 勾选目标模型 → 更新列表**。列表为空或读取失败时，仍可手动录入已确认可用的模型。

回到会话的模型选择器，选择“只因 API · Claude”下的目标模型。模型设置在下一次请求生效。旧会话可能保留自己的历史模型选择，每次切换都看一眼当前选项。

### 可选：换成 GPT 或 DeepSeek

需要一起核对分组 Key、协议、基础地址和模型 ID。官方提供 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 三种协议，一个提供商使用一种协议。

本站 Chat Completions 路线可使用 `https://www.yydsapi.uno/v1` 和相应分组 Key。Responses 要显式选 OpenAI Responses。DeepSeek 也要按本站通道支持的协议配置，不能只改模型名称。

保存配置或获取模型列表成功，只能说明这一步完成；实际连接要通过短任务和本站使用记录验证。

## 04 工作区、权限与计划模式

锚点：`agent-workspace`

1. 在电脑“文档”中新建空的 `agent-practice` 文件夹。
2. 在 Harness 点击**选择工作区**，添加并选中它，再新建会话。即使应用已建立默认工作区，也要核对本课使用的实际目录。
3. 查看会话的 **Permissions / 权限**选择器及范围。首次练习优先用工作区内写入、需要时询问的策略。按当前策略出现审批时，检查目录、命令和动作再确认。

选择工作区与设置权限是两个步骤。“先别修改”属于任务要求，实际操作范围由权限策略决定。

先发送以下短任务：

```text
请先只读检查当前工作区。
告诉我当前目录的完整路径，以及里面有哪些文件。
本次不要创建、修改或删除文件，也不要安装依赖。
```

检查回复的目录是否正确，并在本站使用记录查找同一时间的调用。

### 计划模式

在 Harness 会话输入：

```text
/plan
```

也可以用输入框的**＋ 命令菜单 → 计划**。看到蓝色“计划”状态后再发送规划要求。提交的计划会在右侧打开，读完后用审批操作决定实施或调整。退出时点击蓝色状态按钮，或输入：

```text
/plan off
```

计划模式用于先审方案，权限范围仍单独设置。当前预设没有计划入口时，可以要求先给计划，确认后再发送执行要求。

## 05 完成第一个文件任务

锚点：`agent-task`

以下三步依次发到同一个会话，每一步结束后检查结果。

### 第一步：给出计划

```text
请规划一份给 AI 新手的学习计划，目标文件是当前工作区的 learning-plan.md。
要求：中文，3 个练习，每个约 5 分钟；每个练习都写清操作和完成标准。
先给出内容提纲和准备操作的文件路径，等我确认后再创建文件。
```

### 第二步：确认后创建文件

确认计划只涉及练习目录中的 `learning-plan.md`。若出现计划审批，先批准，再发送：

```text
按刚才确认的计划，在当前工作区创建 learning-plan.md。
如果文件已经存在，请先告诉我，不要覆盖。
标题用“我的 AI 入门计划”。不要改动其他文件。
完成后告诉我实际保存的完整路径，以及如何打开查看。
```

### 第三步：精确修改标题

```text
请把 learning-plan.md 的标题改为“我的第一个 Agent 练习”。
只改标题，保留其他内容。完成后重新读取文件，告诉我改动了哪一处。
```

在电脑中打开文件，检查标题更新，3 个练习、操作和完成标准仍然完整。发现问题时具体追问，例如“第二个练习缺少完成标准，请只补这一项”。

## 06 会话、分叉与子代理协作

锚点：`harness-sessions`

同一份文件继续当前会话；不相关的新任务另开会话；沿用已完成讨论尝试另一方案时分叉；把同一目标拆成多个检查任务时再用子代理。

### 重命名、置顶与搜索

在侧栏会话的“…”或右键菜单选择重命名，例如“AI 学习计划 · 基础版”。常用会话可以置顶。侧栏搜索可以按标题或对话内容寻找历史任务。

### 分叉一个周末版本

1. 等当前一轮结束，在会话菜单选择**分叉 / Fork**。
2. 新会话从最后一个已完成回合创建，**不会自动切换过去**。到侧栏选中新行，改名为“AI 学习计划 · 周末版”。
3. 在新分叉会话中发送：

```text
沿用前面的学习目标，请给出一份适合周末集中练习的版本。
先只在回复里展示，与基础版比较差异，不修改任何文件。
```

分叉继承讨论，不会自动复制或隔离磁盘文件。需要保存另一个版本时，明确另存为 `learning-plan-weekend.md`。两条会话同时工作时，避免一起修改同一文件。

### 两位子代理做只读检查

在支持子代理的预设下，回到主会话发送：

```text
请安排两位子代理只读检查当前工作区的 learning-plan.md。
A：检查每个练习是否有明确操作和完成标准。
B：检查 5 分钟安排是否合理，有没有重复或前后矛盾。
两位都不要改文件，也不要创建定时任务。
请等待两位都完成后，由主会话汇总发现、依据和建议，等我决定是否修改。
如果当前预设不支持子代理，请说明，并由你依次完成这两项检查。
```

生成子代理后，主会话顶部出现数量入口。点开可看运行 / 完成状态，再点子代理查看过程，右侧箭头可在侧栏打开。普通会话列表不一定列出子会话。

支持继续对话的子代理可以追问；旧的一次性子代理历史可能只读。主会话收到全部结果后再统一决定修改，不能把“已分配”当作完成，也不能假设子代理拥有隔离文件目录。

### 复制 ID、归档与停止

- **复制 Session ID**：复制会话标识，便于检索或排错；不是公开分享链接。
- **归档**：整理会话列表。存在运行中的工作时，阅读“停止并归档”确认列出的子代理和后台任务。
- **恢复**：视图选项选“全部对话”或“仅显示已归档”，取消归档后打开。不会自动恢复已停止工作。
- **停止**：中止当前工作。停止、归档或新建会话都不会撤销已写入的文件。

## 07 Skills、插件与 MCP

锚点：`harness-extensions`

基础文件练习不需要安装扩展。出现明确需求时，再判断要补的是流程、能力还是外部工具连接。

| 类型 | 用途 |
| --- | --- |
| Skill | 可复用工作说明，例如按固定步骤审阅文档。 |
| Plugin | 提供工具、界面或集成功能的能力包。 |
| MCP | 连接外部工具服务，配置方式取决于插件和服务。 |

### 调用已安装技能

输入 `/`，从菜单选择当前实际安装的技能，阅读说明，附上材料路径和目标再发送。展开执行中的 **Instructions** 卡片可以检查加载的说明；支持打开的技能项还可以在侧栏查看 `SKILL.md`。名称取决于安装内容，不照搬其他客户端命令。

### 管理插件

打开插件页面，先看已安装列表，再按需要启用或禁用。通过“添加”安装时检查来源、包名、版本和兼容性。

“发现”页依赖**插件 → 实验性插件 → 自定义插件索引**；启用后需要添加可信索引地址，目前没有默认内置索引。没有发现页无需反复修改模型 Key。

### 连接 MCP

确有外部文档库或工具需求时，按对应插件和服务说明配置启动命令或 HTTP 地址，再提供该服务所需授权。用一次小范围读取验证，然后再处理正式材料。

本站模型 Key 不会自动授权第三方工具。MCP 由插件与配置提供，不保证每个版本都有相同图形表单。插件已安装不代表已启用；已启用也不代表外部服务已授权。判断是否生效，看实际调用记录和结果。

## 08 创建一次定时任务

锚点：`harness-automation`

自动化任务在设定时间把指令送进会话，再由模型执行。先做一个只运行一次的小练习。官方 Web 配置提供此功能，当前应用需有“自动化任务”入口。

1. 侧栏进入**自动化任务**，打开“新建”旁的**选择创建方式 → 手动创建**。空页面可以直接点“新建自动化任务”。
2. 名称填“提醒我继续 Agent 练习”，关联工作区选择 `agent-practice`，执行位置选“新建对话并复用”。
3. 输入以下任务内容：

```text
只读查看当前工作区的 learning-plan.md。
根据里面的内容，在本次会话中提醒我可以完成的一个约 5 分钟练习，并列出完成标准。
不要修改文件，不要创建其他自动化任务。
```

4. 运行时间选择**仅一次**，设置几分钟后的实际日期和时间，时区核对为 **Asia/Shanghai**。表单初始时间可能是一小时后，要自行调整。
5. 检查目标目录、下次运行时间、任务内容后创建，保持宿主运行。
6. 到时间后打开详情中的**关联会话 / 最近运行对话**，检查模型是否回复，是否依据学习计划完成。

**任务运行记录保存的是指令投递，不是模型执行结果。**“立即执行”也是再投递一次指令，可能触发模型消费，应继续到会话核对实际结果。

本机 Web UI 的终端进程需要持续运行。关闭浏览器页面与关闭宿主是两回事，宿主停止时不能按时执行。以后使用重复任务时，也要检查运行环境和本站用量。

### 修改、暂停、恢复和删除

在详情修改后点击“保存修改”。暂停停止后续投递，恢复后核对下次时间。删除会移除任务及保存的投递记录，不删除关联会话，也不撤回已经进入队列的消息。

一次性任务投递后显示已结束，可在“全部”或“已结束”查看。宿主重启过、记录与会话结果对不上时，先检查会话再决定重新执行，避免重复处理。

支持提醒工具的主会话也能通过自然语言创建，须写清内容、未来时间、时区和“仅运行一次”，并核对创建卡片。standard、cordis、ptc 预设提供工具；minimal 没有，被委派子代理不能创建或修改提醒。

## 09 检查文件、结果与消费

锚点：`agent-check`

1. 打开工作区内的 `learning-plan.md`，确认标题、3 个练习和完成标准。
2. 子代理等全部结束并汇总；自动化到关联会话看实际回复。
3. 打开本站[使用记录](https://www.yydsapi.uno/usage)，按时间、Key 和模型核对请求。

Agent 一项任务可能多次读取、规划、执行与复查。子代理和定时任务也可能增加调用。模型自报名称不能证明实际通道，以当前选择与本站记录核对。

若需保存预览文件的副本，Web 文件菜单可选“下载”，保存位置由浏览器决定；桌面端可用“另存为”，成功后用“在文件夹显示 / 在 Finder 显示”定位。下载副本与工作区原文件是两份文件，后续修改要明确路径。

## 10 常见问题与完成检查

锚点：`agent-help`

| 现象 | 先检查 |
| --- | --- |
| 输入框不可用 | 工作区、已保存提供商、当前会话模型；旧会话可能保留已删除模型。 |
| MISSING_CREDENTIAL / 401 | 重新保存完整 Key，检查空格、分组、额度及模型权限。 |
| UNKNOWN_MODEL | 模型 ID 与显示名称不同，添加精确 ID 后在会话选中。 |
| 模型列表获取失败 | 可以手动录入本站确认可用的 ID，列表探测不等于实际调用。 |
| 400 / 404 | 协议与基础地址。本课 Anthropic 使用根地址，不填完整 `/v1/messages`。 |
| 缺少计划、技能、子代理或自动化入口 | 当前预设、插件与应用版本；先完成主会话基础任务。 |
| 分叉后仍在原会话 | 创建不会自动切换，去侧栏选择新会话；须有已完成回合。 |
| 说完成却找不到文件 | 核对实际工作区和完整路径，打开文件；检查是否等待审批。 |
| 自动化有记录但无结果 | 投递记录不代表执行完成，去关联会话查实际回复。 |
| 关闭终端后 Web UI 不可用 | 重启本机宿主，打开打印地址，检查启动日志与端口。 |

完成基础练习后即可开始自己的小任务。每次写清目录、目标文件、允许改动和完成标准。
