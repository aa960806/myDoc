在 Codex 等 Agent 中生图

建好生图技能（Skill），在对话里描述画面即可出图。

本页步骤

  1. 01准备模型和密钥
  2. 02创建生图技能
  3. 03生成第一张图

01准备模型和密钥

  • 在模型广场复制完整模型 ID，记下生图分组。
  • 在API 密钥页选同一分组，创建并复制 Key。已有该组的普通 Key 可直接用。

02创建生图技能

用 Codex 或支持 Skill 的 Agent 打开练习文件夹。填好模型和 Key，复制提示词发给 Agent。

可换成本分组的其他模型。

固定生图地址 https://image.yydsapi.uno

提示词在本机生成，含完整 Key。只发给可信 Agent，对话记录可能保留 Key。

查看提示词模板 
请为当前 Agent 创建一个名为 zhiyin-image 的本地生图 Skill。完成后告诉我保存位置和调用方法。

接入信息
生图地址：https://image.yydsapi.uno
接口：POST https://image.yydsapi.uno/v1/images/generations
请求体示例：{"model":"{{IMAGE_MODEL}}","prompt":"用户的画面描述"}
本次配置用的生图 API Key：{{IMAGE_API_KEY}}

请按以下方式实现：
1. 按当前 Agent 的 Skill 规范创建 SKILL.md 和可运行的生图脚本。Codex 使用当前项目的 .agents/skills/zhiyin-image/，在 SKILL.md 的 YAML 文件头填写 name: zhiyin-image，并用 description 说明何时调用。其他 Agent 使用其支持的技能目录。如果已存在同名技能，先告诉我再修改。
2. 脚本从 ZHIYIN_IMAGE_API_KEY 环境变量或当前用户的系统凭据库读取 Key。将本次提供的 Key 配置在本机可安全保存的位置；如不能安全写入，请给我一个本机隐藏输入的方法。不要把真实 Key 写入技能文件、项目、命令行参数、日志或回复。
3. 用户要求生图时，使用示例中的 model，把用户的画面描述填入 prompt。张数、尺寸等可选参数按该模型支持的取值设置。只向上述 HTTPS 生图接口发送 Authorization: Bearer <运行时读取的 Key> 和 Content-Type: application/json，不向其他地址转发凭据。
4. 成功后从 data[0].b64_json 解码图片，或从 data[0].url 下载图片（下载不带鉴权头）。核对是有效图片，按实际格式、用新文件名保存到当前工作区的 outputs/，回复可打开的文件路径。
5. 这次只创建 Skill，用模拟响应检查脚本。等我明确描述要生成的图后，再发一次生图请求。出错或超时时给出脱敏提示，不要自动重复提交。

03生成第一张图

技能保存后，在同一项目发送下面的指令。若找不到技能，在该项目新开对话。

使用 zhiyin-image，帮我画一只坐在雨天窗边的橘猫，暖色插画风，正方形，生成 1 张并保存到当前工作区。

打开返回的文件查看图片。费用按生图分组计算，可查使用记录。超时也先查记录，再决定是否重试。
