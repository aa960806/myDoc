自动配置

填入 Key，选择文件夹，即可备份并更新配置。

请用电脑上的最新版 Chrome 或 Edge 打开本站 HTTPS 页面，或按教程手动配置。

填写连接信息

Claude 桌面端和 DeepSeek Harness 请在各自的设置页配置。

Key 仅在本机处理，浏览器不保存。

可更换模型，请填写 Key 所属分组支持的 ID。

选择配置文件夹

Windows 用户在文件选择窗口的地址栏粘贴：

%USERPROFILE%\.codex

选中 .codex 并允许写入。若找不到此文件夹，在用户目录新建同名文件夹。

将保存到 .codex/config.toml。已有文件会先在原目录备份。

先安装并退出客户端，再写入配置。

未弹出窗口？请用电脑版 Chrome 或 Edge 打开本页。

DeepSeek 用户请在 Harness 中配置 ↗

写入范围、恢复备份与其他系统

服务地址固定为 https://www.yydsapi.uno。仅更新所选文件，不安装工具、不改系统环境变量、不发起收费请求。

更新连接地址、Key 和模型，保留其他设置。Claude Code 会清理文件中冲突的认证项和云服务设置。配置未生效时，检查环境变量和项目配置。

Codex 使用独立的 zhiyin_api 供应商，其他供应商、插件和项目设置保留。TOML 会重新排版，原注释可在备份中查看。遇到默认 profile 或特殊配置会停止合并。

需要恢复时，先退出客户端，将同目录中的 config.toml.backup-… 或 settings.json.backup-… 复制回原文件名。备份也可能含有 Key，请保存在自己电脑上。

macOS / Linux 选择用户目录中的 .codex 文件夹。隐藏文件夹需在系统选择窗口中显示。自定义配置目录、WSL 或公司托管环境，请按客户端实际位置手动配置。

保存后重启客户端，发送消息验证连接、模型权限和可用额度。
