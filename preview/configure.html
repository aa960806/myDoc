自动配置

填好 Key，选择配置文件夹。备份、合并和保存交给网页完成。

当前浏览器不支持授权写入。请使用电脑上的最新版 Chrome 或 Edge 打开本站 HTTPS 页面；也可以按教程手动配置。

仅在本机处理，不上传、不存入浏览器。

已填入教程示例。请确认你的 Key 分组支持该模型，可自行修改。

选择哪个文件夹？

Windows：在文件选择窗口的地址栏粘贴

%USERPROFILE%\.codex

选中 .codex 文件夹并允许写入。若还不存在，可在用户目录中新建同名文件夹。

将保存到 .codex/config.toml。已有文件会先在原目录备份。

这里配置 Claude Code。Claude 桌面端和 DeepSeek Harness 使用各自的设置界面。

开始前请先安装并退出客户端，避免它同时修改配置。

未弹出文件选择窗口时，请在电脑的 Chrome 或 Edge 中打开本页。

保存范围、恢复方法与其他系统

服务地址固定为 https://www.yydsapi.uno。本站仅处理你选中的配置文件，不安装工具、不修改系统环境变量，也不会自动发起收费请求。

更新连接地址、Key 和模型，保留其他设置。Claude Code 会清理同一文件中冲突的旧认证项与云服务选择；环境变量或项目级配置仍可能覆盖此文件，需要在客户端检查。

Codex 使用独立的 zhiyin_api 供应商，其他供应商、插件和项目设置保留。TOML 会重新排版，注释保留在备份文件中；已启用默认 profile 或特殊配置时会停止自动合并。

需要恢复时，先退出客户端，将同目录中的 config.toml.backup-… 或 settings.json.backup-… 复制回原文件名。备份也可能含有 Key，请保存在自己电脑上。

macOS / Linux 选择用户目录中的 .codex 文件夹。隐藏文件夹需在系统选择窗口中显示。自定义配置目录、WSL 或公司托管环境，请按客户端实际位置手动配置。

“保存成功”表示本机文件已写入并核对；模型权限、余额和实际连通性，需要重启客户端后验证。
