# Model brand icons

The model introduction directory uses OpenAI, Claude, DeepSeek and Grok SVG marks from `@lobehub/icons-static-svg` version `1.103.0`.

- Upstream: https://github.com/lobehub/lobe-icons
- Package: https://www.npmjs.com/package/@lobehub/icons-static-svg/v/1.103.0
- Sources: `openai.svg`, `claude-color.svg`, `deepseek-color.svg`, `grok.svg`.
- License: MIT; see [the included license](../../licenses/lobe-icons.txt).

SVG geometry is unchanged. Colored variants retain their original colors; OpenAI and Grok are inverted by CSS in the dark theme. Brand names and marks belong to their respective owners.
